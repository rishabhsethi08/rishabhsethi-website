# Recovery prototype snapshot

Source: https://disruption-management-prototype.vercel.app/
Retrieved: 14 October 2026. Original public build: index-D23rG4uE.js and index-ChHdbfcU.css.

This is the original compiled prototype, mounted in a shadow root on the case-study page. It does not use a remote iframe. Fonts and the original image URLs still require a network connection.

Adapter changes: export a mount/unmount function, use a fixed local stage, resolve the plane image relative to this module, and turn telephone links into a demonstration notice. The CSS document tokens are mapped to the shadow host. Original screen content and interactions are retained.

To replace this snapshot, use the original project source when it becomes available. Do not edit the minified bundle for ordinary case-study changes.

The lock-screen notification uses the user-supplied `blinctrip-icon.svg`. Its orange easyJet background was removed. Airline icons within flight details retain their original branding.
